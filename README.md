This project analyzes Netflix's content library to uncover trends, patterns, and business insights using Python-based data analysis and visualization techniques.
The analysis includes content type distribution, genre popularity, country-wise content production, growth trends, audience ratings, movie durations, and top directors.

Key Insights
Netflix contains significantly more movies than TV shows.
Drama and international content dominate the platform.
The United States produces the highest amount of Netflix content.
Netflix experienced rapid content growth after 2015.
TV-MA and TV-14 ratings are most common.
Most movies are between 80–120 minutes long.
